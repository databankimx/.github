# Databank IMX LLC

Welcome to the official GitHub organization for **Databank IMX LLC**. Here we publish open, hands-on developer training material for teams building on modern languages and the Hyland OnBase platform.

## What you'll find here

Our public repositories are structured, self-paced training courses. Each one is organized as a progression of lessons with runnable example code, so you can learn by reading and by doing.

## Public repositories

| Repository | Focus | Language | License |
| --- | --- | --- | --- |
| [training-csharp-and-onbase](https://github.com/databankimx/training-csharp-and-onbase) | C# fundamentals and the OnBase Unity API | C# | MIT |
| [training-python](https://github.com/databankimx/training-python) | Developer training in Python | Python | MIT |

### training-csharp-and-onbase

C# and OnBase Unity API training. Works through core C# language concepts chapter by chapter, from a first "Hello World" through program structure, control flow, and object-oriented design, then moves into integrating with the OnBase Unity API.

### training-python

Developer training in Python, covering the language from the ground up for engineers getting productive with Python.

## Getting started

1. Pick the repository that matches what you want to learn.
2. Clone it and follow the lessons in order. Each lesson folder builds on the one before it.
3. Run the example projects as you go to reinforce each concept.

```bash
git clone https://github.com/databankimx/training-csharp-and-onbase.git
# or
git clone https://github.com/databankimx/training-python.git
```
